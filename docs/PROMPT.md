# 优化版需求提示词（v3，对应 InvestAI 2.0）

> 在《AI 协助投资管理系统升级需求回复》基础上的修改：①把「流程」拆成数据结构（阶段 / 工作 / 决策节点 / 结果去向），否则无法配置也无法验收；②权限明确为四层并要求 AI 继承同一套判定；③AI 边界写成可测试的规则（哪些工具永远不给）；④模型路由按资料密级而不是总开关；⑤每条需求配一条可自动执行的验收用例；⑥外部依赖（模型、推送、统一登录、行情）写清楚需要谁提供什么。

---

为投资管理机构交付 **InvestAI**：一个可运行的系统（DSH 插件 + 独立服务端），支撑投资业务全流程，AI 在权限范围内协助办公但不做正式决策。

## 1. 流程（可配置，财务投资优先）
- 业务类型：财务投资、并购重组、上市公司资本运作、基金业务、资本招商、产业投资、其他。每类一份**结构化流程定义**，后台表单可改，有版本，发布不影响在途项目。
- 定义 = 阶段（名称、项目状态名）→ 具体工作（工作类型、是否必做、默认岗位）→ 决策节点（审批 / 上会 / 会签；表决岗位与所需业务操作权限；规则：任一 / 全体 / 过半 / 三分之二；上会必备材料；每种结果的去向：推进到某阶段、退回补充、继续持有、完成、终止）。
- 必做工作的成果定稿 = 阶段准入条件；未满足不能发起决策。另支持暂停、恢复、终止、重新推进、人工退回。
- 财务投资主线：项目机会 → 启动审批 → 立项准备 → 立项会 → 尽调 → 尽调结论确认 → 投资决策 → 投委会 → 交易执行 → 交割会签 → 投后 → 退出决策 → 退出 → 复盘归档。

## 2. 权限（四层，服务端判定，AI 复用）
功能权限 · 数据范围（本人 / 本部门 / 指定授权 / 投后 / 全机构）· 业务操作（启动授权、材料定稿、上会表决、投决、交易确认、退出审批、归档确认）· 敏感字段（金额 / 估值 / 条款 / LP / 商业秘密）与资料密级（公开 / 内部 / 机密 / 绝密）。预设 11 个岗位，可增改。AI 看到的资料 = 当前用户能看到的资料，敏感字段进入模型前脱敏。

## 3. AI 边界
- 参与级别：关闭 / 辅助建议 / 起草待确认 / 授权执行；按岗位、业务类型、工作类型、资料密级分别设上限，取最低。
- AI 永远没有：表决、审批、定稿、推进阶段、删除、全量导出。产出一律为「待人工确认」的草稿或记录。
- 模型路由：外部 / 本地（仅本机回环地址）/ 混合。默认「机密」及以上只交给本地模型；没有本地模型时用离线引擎，不外发。

## 4. 场景
1. **会议纪要**：录音 → 本机转写（热词、术语校正）→ 讨论要点、决定事项、待办、责任人（只从参会人中选）、期限 → 人工确认 → 纪要定稿入项目，待办生成任务并提醒。
2. **文档**：标准文书按固定模板填充（缺失标【待补充】，不调用模型）；研究类成果先由 AI 参考历史成果与写作规范规划结构，用户确认后起草。输出真实 Word / PPT / Excel，可用本机 Office 编辑后提交为新版本；版本可恢复，定稿可撤回（需原因）；可导出 PDF。
3. **数据收集**：外部一次性授权链接（有效期、可撤销、只存哈希、附件白名单）；AI 从 BP / 工商 / 财报提取；人工确认后写入同一公司库，保留来源与确认人。
4. **固定格式转换**：BP → 项目信息表、财报 → 财务分析表、尽调材料 → 尽调汇总；每个字段标来源与页码；缺失、多源冲突单独列出；审计口径优先于 BP；导出 Excel / PDF。

## 5. 路线图（全部纳入本期）
先做：真实 DeepSeek + 评测集、PDF 解析、智堡定时采集入库、Word / PDF 导出。再做：可配置流程与准入、事件触发与 AI 预审、企业微信 / 飞书 / 钉钉推送、服务端数据库与统一登录。最后做：指标库与结构化抽取、引用内容核对、公司观点库、行情（授权数据）与公告、录音转写。

## 6. 验收（必须自动化）
每条需求至少一条可执行用例：全流程从机会走到归档（含退回、回避、继续持有、会签）；四层权限各有拒绝用例；机密资料未发往外部模型（用探针模型证明）；提取的冲突 / 缺失 / 来源；模板缺失字段；真实录音转写与待办责任人；外部链接单次与撤销；推送加签；统一登录 state / PKCE；流程版本隔离；历史回滚与重启一致性。另建评测集衡量引用核对率与提取准确率，接入真实模型后对比。

## 7. 需要机构提供
DeepSeek API Key（或本地模型）、智堡 API Key、群机器人 Webhook 与加签密钥、统一登录应用凭据、授权行情数据、正式模板与历史成果样本、首批试点用户名单。
