## 1. 选择使用方式

| 你的情况 | 推荐方式 | 需要准备 |
|---|---|---|
| 个人或演示，想双击就用 | **桌面应用**（第 2 节） | 无 |
| 已经在用 DeepSeek Harness（DSH），希望在 DSH 里直接使用 | **DSH 插件**（第 3 节） | DSH 桌面版 0.2 或命令行版 |
| 团队多人同时使用、需要账号与权限管理 | **云服务器**（第 7 节） | 一台 Linux 服务器 + 域名（HTTPS） |
| 二次开发、调试 | **源码运行**（第 8 节） | Node.js 22.13 及以上 |

四种方式运行的是同一套程序，功能一致；区别在于是否需要登录、数据存在哪里、AI 模型从哪里来。桌面应用和 DSH 插件可以在同一台电脑上同时安装，**互不冲突**（见第 9 节）。

## 2. 方式一：桌面应用（推荐）

### 2.1 下载

打开 [GitHub Releases](https://github.com/evanzhu0105-ship-it/InvestAI-Desktop/releases/latest)，按电脑下载一个文件：

| 电脑 | 下载 | 如何判断 |
|---|---|---|
| Mac（Apple 芯片：M1 / M2 / M3 / M4） | `InvestAI-x.y.z-mac-arm64.dmg` | 左上角  →「关于本机」，「芯片」一栏写着 Apple M… |
| Mac（Intel） | `InvestAI-x.y.z-mac-x64.dmg` | 「处理器」一栏写着 Intel |
| Windows 10 / 11 | `InvestAI-x.y.z-win-x64.exe` | 「设置 → 系统 → 系统信息」显示 64 位操作系统 |

> 仓库为私有时，需要先登录 GitHub 并被添加为仓库协作者，否则下载页显示 404。也可以由管理员把安装包直接发给你。

### 2.2 在 Mac 上安装

1. 双击下载的 `.dmg`，在弹出的窗口中把 **InvestAI** 图标拖到 **Applications（应用程序）** 文件夹。
2. 打开「应用程序」，双击 **InvestAI**。
3. 第一次打开会出现安全提示（安装包未使用付费的 Apple 开发者证书签名，属正常现象）：
   - **macOS 15（Sequoia）及更新**：在提示框点「完成」，然后打开 **系统设置 → 隐私与安全性**，滚动到底部，在「已阻止打开 InvestAI」旁点 **仍要打开**，输入开机密码确认。
   - **macOS 14 及更早**：在「应用程序」中 **右键（或按住 Control 点按）InvestAI → 打开 → 打开**。
   - 若提示 **「已损坏，无法打开」**：打开「终端」，输入下面这行并回车，然后再打开：
     ```bash
     xattr -cr /Applications/InvestAI.app
     ```
4. 以后直接双击打开即可，不会再提示。

### 2.3 在 Windows 上安装

1. 双击下载的 `.exe`。
2. 如果出现蓝色的 **「Windows 已保护你的电脑」**（SmartScreen）：点 **更多信息 → 仍要运行**。
3. 按安装向导操作：可以选择安装位置；**不需要管理员权限**；完成后桌面和开始菜单会出现 **「InvestAI 投研工作台」**。
4. 双击桌面图标打开。程序只在本机 `127.0.0.1` 上通信，不对局域网开放端口。

### 2.4 菜单说明

| 菜单 | 项目 | 作用 |
|---|---|---|
| 账户 | 本机模式 / 登录模式 | 本机模式免登录、可切换演示岗位；登录模式用账号密码登录（第 5 节） |
| 账户 | 演示账号与权限（Excel） | 打开 15 个演示账号与权限分层表 |
| 帮助 | 打开数据目录 | 数据库、资料、成果文件所在位置（备份用） |
| 帮助 | 在浏览器中打开 | 用系统浏览器打开同一个界面 |
| 视图 | 放大 / 缩小 / 实际大小 | 调整界面字号 |

## 3. 方式二：DeepSeek Harness 插件

插件形式下，工作台的各个页面（工作台、项目管理、会议纪要……）出现在 DSH 左侧栏，界面跟随 DSH 主题，AI 直接使用你在 DSH 中配置的 DeepSeek 模型；DSH 自己的对话中也可以调用工作台的项目与资料工具。

**版本要求**：DSH 0.1.x 或 0.2.x；InvestAI **2.4 及以上**（2.3 及以前在 DSH 0.2 中保存、表决等写操作会提示「跨站请求被拒绝」，请升级）。

### 3.1 DSH 桌面版（Mac / Windows 通用）

1. 从 Releases 下载 `investai-desktop-x.y.z.tgz`。
2. **把它放到一个不会删除的固定位置**（DSH 会记住这个路径，之后重新安装依赖时还要用到），例如：
   - Mac：`/Users/你的用户名/DSH-插件/investai-desktop-2.4.0.tgz`
   - Windows：`C:\Users\你的用户名\DSH-插件\investai-desktop-2.4.0.tgz`
3. 打开 DSH 桌面版，点左侧栏的 **插件**（或「设置 → 插件」），点 **添加插件 → 安装第三方插件**。
4. 在「包名或地址」中填写 tgz 的**完整路径**（必须是绝对路径）：
   - Mac：在访达中选中文件，按 `⌥ Option + ⌘ Command + C` 复制路径后粘贴。
   - Windows：按住 `Shift` 右键文件 →「复制文件地址」，粘贴后**去掉两端的引号**。
5. 点 **安装**。DSH 会提示「请确认插件来源可信」——本插件不需要运行安装脚本，确认即可。首次安装会从 npm 下载约 200 个依赖包（约 1 分钟，需要联网）。
6. 看到 **「已安装，请重启 DSH 加载它」** 后，完全退出 DSH（Mac：`⌘Q`；Windows：关闭所有 DSH 窗口，必要时在任务管理器中确认 DeepSeek Harness 已结束）再打开。
7. 左侧栏出现「工作台、项目管理、会议纪要……」即安装成功。
8. 在 DSH **设置 → 模型** 中填写 DeepSeek API Key，工作台的 AI 会自动使用（优先 DeepSeek V4.1 Flash）。

> 网络较慢或无法访问 npm 时：在 DSH 插件页点 **更换安装源** 选择国内镜像；或在用户目录的 `.npmrc` 文件中写入 `registry=https://registry.npmmirror.com`（Mac：`~/.npmrc`；Windows：`C:\Users\你的用户名\.npmrc`）。

**升级插件**：DSH 不支持原地升级。在插件页先 **卸载** 旧版本，再按上面步骤安装新的 tgz，重启 DSH。工作台数据不受影响（数据不在插件目录里）。

**也可以从 GitHub 安装**：在「包名或地址」中填 `github:evanzhu0105-ship-it/InvestAI-Desktop#v2.4.0`（私有仓库需要先在 DSH 中连接有访问权限的 GitHub 账号）。

### 3.2 DSH 命令行 / 网页版

```bash
dsh plugin --profile web add /绝对路径/investai-desktop-2.4.0.tgz
dsh web
```

Windows（PowerShell）：

```powershell
dsh plugin --profile web add C:\Users\你的用户名\DSH-插件\investai-desktop-2.4.0.tgz
dsh web
```

也可以把源码目录作为插件（开发时用）：`dsh plugin --profile web add /绝对路径/InvestAI-Desktop`，Mac / Linux 可直接运行 `sh scripts/install-dsh.sh`。

卸载：`dsh plugin --profile web remove @local/investai-desktop`。

### 3.3 DSH 中的注意事项

- 「设置 → 内置插件」中 `plugin-market/tools 已停用` 是 DSH 的默认状态（可选的插件市场组件），与本插件无关，不需要处理。
- DSH 0.2 第一次启动会先显示「预览版说明」与引导，界面可能短暂是浅色；关掉说明后即恢复深色主题。
- 打印 / 导出 PDF 会打开系统打印对话框，选择「存储为 PDF」（Mac）或「Microsoft Print to PDF」（Windows）。
- 插件形式是单人使用（可切换演示岗位）；多人登录请用桌面应用的登录模式或云服务器。

## 4. 第一次使用

1. 打开后会自动播放 **5 步界面导览**（左侧导航、工作台、身份、AI 协作助手、帮助）。可随时点「跳过」，之后在右上角 **ⓘ 帮助中心** 重新查看。
2. 程序自带一套**虚构的演示数据**：8 家公司、8 个项目、15 个岗位，可以放心操作。
3. **配置 AI（可选）**：「系统配置 → AI 策略与模型」中填写 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 获取；DSH 插件形式改在 DSH 设置中填写），保存后点「测试连接」确认 Key、模型与网络都正常。不填也能用：AI 使用离线引擎（资料原文摘录 + 规则），只是不会改写润色。
4. **体验不同岗位**：本机模式下点右上角头像，切换为合伙人、投资经理、风控、法务等 15 个演示身份，每个身份能看到的项目、敏感字段和能做的操作都不同。
5. 遇到灰色按钮：点一下会说明原因（缺什么权限、前置条件没满足）以及可以找谁。

## 5. 账号与权限

### 5.1 四层权限

| 层 | 控制什么 | 举例 |
|---|---|---|
| ① 功能权限 | 能用哪些模块与动作 | 新建项目、上传资料、配置流程 |
| ② 数据范围 | 能看哪些项目 | 本人负责 / 本部门 / 指定授权 / 投后 / 全机构 |
| ③ 业务操作 | 流程节点上的关键动作 | 启动授权、材料定稿、上会表决、投资审批 |
| ④ 敏感信息 | 字段类别 + 资料密级 | 投资金额、估值、交易条款；公开 / 内部 / 机密 / 绝密 |

AI 继承当前用户的全部权限，看不到的内容 AI 也看不到；AI 没有表决、定稿、推进、删除、导出的能力。

### 5.2 演示账号（权限分层）

[accounts/InvestAI-演示账号与权限.xlsx](accounts/InvestAI-演示账号与权限.xlsx) 列出 15 个演示账号、初始密码和权限，按大小分为：决策层（合伙人）→ 管理层（部门负责人）→ 执行层（投资经理、投后）→ 专业支持层（风控、法务、财务、基金募资）→ 协作层（分析师、综合协作），另有系统管理员。

使用方法：

- 桌面应用：菜单 **账户 → 登录模式**，应用重新打开后显示登录页，用表中账号登录。
- 命令行：`node server.mjs --demo-accounts`。

> 演示密码公开在仓库中，**只用于演示和培训**。正式使用请部署云服务器（第 7 节），系统会为每个账号生成随机密码。

### 5.3 修改密码与管理账号

- **修改自己的密码**：点右上角头像 → 修改密码（至少 8 位，可在「系统配置 → 云端与安全」中调整）。改完后，你在其他电脑上的登录会自动退出。
- **管理员**：「系统配置 → 组织与人员」新增、停用人员或重置密码；「岗位权限」调整各岗位的四层权限。被重置密码的人下次登录必须先改成自己的密码。
- **安全设置**（「系统配置 → 云端与安全」）：闲置自动退出时间、连续输错锁定次数与时长、密码最少位数；可查看谁在线并强制退出。

## 6. 日常使用

| 我想… | 去哪里 | 怎么做 |
|---|---|---|
| 看今天要处理什么 | 工作台 | 「轮到你」列出待表决、待审核、到期任务 |
| 新建项目 | 工作台右上角「+ 录入项目机会」 | 选业务类型，系统按该类型的流程生成阶段与工作 |
| 推进项目 | 项目详情 →「下一步」 | 显示还差哪些必做工作、谁负责；满足准入条件后发起审批或上会 |
| 起草成果（立项报告、尽调报告等） | 项目详情 → 成果 → AI 起草 | AI 先列大纲、你确认后起草；成稿是真实的 Word / PPT / Excel，可用本机 Office 编辑后提交新版本 |
| 表决 | 工作台「待表决」 | 查看准入检查结果与材料后投票；结果按流程配置的规则（任一 / 全体 / 过半 / 三分之二）自动生效 |
| 整理会议纪要 | 会议纪要 | 上传录音（需安装转写引擎）或粘贴文字稿 → AI 提取决定事项、待办、责任人 → 人工确认 → 待办自动生成任务 |
| 从 BP / 财报提取数据 | 智能提取 | 上传文件 → 生成项目信息表 / 财务分析表，每个数字标来源与页码，冲突单独列出 → 确认后写入公司库 |
| 让外部公司自己填资料 | 项目详情 → 外部填报 | 生成一次性链接（1–14 天、可撤销），对方填写后你确认入库（需要多人登录模式或云服务器） |
| 打印 / 导出 PDF | 成果或提取结果 →「打印 / PDF」 | 系统打印对话框中选择「存储为 PDF」 |
| 修改流程 | 系统配置 → 流程配置 | 增删阶段、工作、准入条件与决策规则，发布新版本（不影响进行中的项目） |

### 会议录音转写（可选，约 480MB）

录音只在本机转写，不上传。需要先安装 [uv](https://docs.astral.sh/uv/)，然后：

- **桌面应用**：打开「会议纪要」，页面顶部会显示适合你电脑的完整安装命令，复制到终端（Mac）或 PowerShell（Windows）运行，完成后重新打开该页。
- **源码 / DSH 插件**：Mac / Linux 运行 `sh scripts/setup-asr.sh`；Windows 运行 `powershell -ExecutionPolicy Bypass -File scripts\setup-asr.ps1`。

不安装也可以在会议中「粘贴文字稿」整理纪要。

## 7. 方式三：云服务器（多人共用）

适合团队：每人用自己的账号登录，权限按岗位分层，数据集中在服务器上。完整说明见 [CLOUD.md](CLOUD.md)，最简步骤：

```bash
git clone https://github.com/evanzhu0105-ship-it/InvestAI-Desktop.git && cd InvestAI-Desktop
cp .env.example .env                      # 填写 DEEPSEEK_API_KEY
docker compose up -d --build              # 服务只监听本机 4310 端口
docker compose exec investai cat /data/initial-credentials.txt   # 各账号的随机初始密码
```

再用 Caddy 或 Nginx 配置 HTTPS 域名转发到 `127.0.0.1:4310`。上线前按 [CLOUD.md 第 4 节](CLOUD.md#4-上线检查清单) 的清单检查。

**信息同步（预留）**：云端管理员可在「系统配置 → 云端与安全 → 设备令牌」为其他电脑或程序签发令牌，对方通过同步接口按令牌所属人员的权限增量获取数据；推送修改到云端的接口已预留，云服务器上线后启用。

## 8. 方式四：从源码运行（开发者）

需要 Node.js 22.13 及以上（推荐 24）：Mac 用 [nodejs.org](https://nodejs.org) 安装包或 `brew install node`；Windows 用 nodejs.org 的 `.msi` 安装包或 `winget install OpenJS.NodeJS.LTS`。

```bash
git clone https://github.com/evanzhu0105-ship-it/InvestAI-Desktop.git
cd InvestAI-Desktop
npm install                       # 必须先安装依赖
node server.mjs --desktop         # 本机模式，打开 http://127.0.0.1:4310
```

| 命令 | 作用 |
|---|---|
| `node server.mjs --desktop` | 本机模式（免登录，可切换岗位） |
| `node server.mjs` | 多人登录模式，随机初始密码在 `data/initial-credentials.txt` |
| `node server.mjs --demo-accounts` | 多人登录 + Excel 中的演示密码 |
| `node server.mjs --data <目录> --port <端口>` | 指定数据目录与端口 |
| `node --test --test-concurrency=1 "test/*.test.mjs"` | 回归测试 |
| `node scripts/verify.mjs` | 135 项验收 |
| `cd desktop && pnpm install && pnpm run dist` | 打包 Mac 与 Windows 安装包（在 Mac 上可同时产出两个平台，见 [desktop/README.md](../desktop/README.md)） |

## 9. 适配说明

### 9.1 系统与版本

| 项目 | 支持范围 | 说明 |
|---|---|---|
| macOS | 12 Monterey 及以上，Apple 芯片与 Intel 分别有安装包 | Intel 版也可在 Apple 芯片上经 Rosetta 运行，但建议用对应版本 |
| Windows | 10 / 11，64 位 | 安装到当前用户目录，不需要管理员权限 |
| Linux | 服务器部署（Docker 或 Node 24） | 桌面安装包暂不提供 |
| DeepSeek Harness | 0.1.x、0.2.x（桌面版与命令行版） | 插件需 InvestAI 2.4+ |
| Node.js（源码 / 服务器） | 22.13 及以上 | 使用内置 SQLite，无需单独安装数据库 |
| 浏览器（云服务器 / 网页） | 最新版 Chrome、Edge、Safari、Firefox | |
| Office | Microsoft Office、WPS 均可 | 成果文件为标准 .docx / .pptx / .xlsx |

### 9.2 与 DeepSeek Harness 桌面版共存

桌面应用和 DSH 桌面版可以同时安装、同时运行，彼此不读写对方的任何文件：

| | InvestAI 桌面应用 | InvestAI 作为 DSH 插件 | DeepSeek Harness 桌面版 |
|---|---|---|---|
| 程序标识 | `com.investai.workbench` | 运行在 DSH 内 | DSH 自己的标识 |
| 数据目录 | Mac `~/Library/Application Support/InvestAI`；Windows `%APPDATA%\InvestAI` | `~/.dsh/investai`（Windows `%USERPROFILE%\.dsh\investai`） | `~/.dsh`、DSH 应用数据 |
| 端口 | 本机 127.0.0.1，首次随机分配后沿用，被占用时自动更换 | 使用 DSH 的地址 | DSH 自己的端口 |
| 密钥 | 数据目录下 `secrets.json` | `~/.config/investai/secrets.json` | DSH 自己的配置 |

桌面应用与 DSH 插件的数据**相互独立**，需要同一份数据时请只使用其中一种，或用「帮助 → 打开数据目录」手动复制。

### 9.3 AI 模型

| 模型来源 | 适用 | 配置 |
|---|---|---|
| DeepSeek（外部） | 一般资料与公开信息 | 桌面应用 / 服务器：系统配置 → AI 策略与模型；DSH 插件：DSH 设置 → 模型 |
| 本地模型（Ollama 等） | 「机密」及以上资料 | 系统配置 → AI 策略与模型 → 本地模型，只允许本机地址 |
| 离线引擎 | 未配置任何模型时 | 自动启用，不调用任何模型 |

## 10. 数据、备份、升级与卸载

| 操作 | 桌面应用 | DSH 插件 | 云服务器 |
|---|---|---|---|
| 数据位置 | 菜单「帮助 → 打开数据目录」 | `~/.dsh/investai` | `./data`（Docker 挂载） |
| 备份 | 退出应用后复制整个数据目录 | 退出 DSH 后复制 `~/.dsh/investai` | 见 CLOUD.md 第 4 节 |
| 升级 | 直接安装新版本覆盖（Mac 拖入替换；Windows 运行新安装包），数据保留 | 先卸载再安装新 tgz，数据保留 | `git pull && docker compose up -d --build` |
| 卸载 | Mac：把「应用程序」中的 InvestAI 移到废纸篓；Windows：「设置 → 应用」中卸载「InvestAI 投研工作台」 | DSH 插件页卸载 | `docker compose down` |
| 彻底删除数据 | 卸载后手动删除数据目录（卸载不会自动删除） | 删除 `~/.dsh/investai` | 删除 `./data` |
| 恢复演示数据 | 退出后把数据目录中的 `data` 文件夹改名，重新打开会生成新的演示数据 | 退出 DSH 后把 `~/.dsh/investai` 改名 | 停止服务后把 `./data` 改名 |

## 11. 常见问题与排错

| 现象 | 原因与解决 |
|---|---|
| GitHub 下载页或邀请链接显示 **404** | 仓库是私有的：先在浏览器中**登录 GitHub**（要用被邀请的那个账号），再打开链接。聊天软件内置的浏览器经常未登录，请改用 Safari / Chrome。协作邀请在 https://github.com/evanzhu0105-ship-it/InvestAI-Desktop/invitations 接受，7 天内有效 |
| Mac 提示「无法验证开发者」「已损坏」 | 见 2.2 第 3 步 |
| Windows 提示「已保护你的电脑」 | 点「更多信息 → 仍要运行」 |
| DSH 中保存、表决等操作提示 **「跨站请求被拒绝」** | 插件版本过旧（2.3 及以前），按 3.1「升级插件」安装 2.4 及以上 |
| DSH 插件安装失败 / 一直在下载 | 网络无法访问 npm：在插件页「更换安装源」或配置 `.npmrc` 镜像（见 3.1）；路径必须是绝对路径且文件仍在原位置 |
| DSH 左侧栏没有出现工作台 | 安装后需要完全退出并重新打开 DSH；在插件页确认插件状态为「已安装」且已启用 |
| 打印 / 导出 PDF 没反应 | 2.4 起改为系统打印对话框，请升级；或下载 Word 版本后另存为 PDF |
| 每次打开都重新播放导览 | 2.3 起已修复（端口沿用），请升级 |
| AI 回答只有原文摘录 | 未配置模型时使用离线引擎；在第 4 节第 3 步填写 DeepSeek API Key |
| 涉及机密资料时 AI 不调用 DeepSeek | 正常：「机密」及以上资料默认只交给本地模型，可在「AI 策略与模型」调整阈值 |
| 登录提示「已锁定」 | 连续输错次数过多，等待锁定时间（默认 15 分钟）后再试，或请管理员在「云端与安全」中处理 |
| 忘记密码 | 请管理员在「组织与人员」中重置；你下次登录时需要设置新密码 |
| 会议录音无法转写 | 未安装转写引擎，见第 6 节「会议录音转写」；或在会议中粘贴文字稿 |
| 想清空重来 | 见第 10 节「恢复演示数据」 |
